# Single / Team 最小对照

OpenAI Agents SDK 0.22.2 负责流程，通过 AsyncOpenAI 与 OpenAIChatCompletionsModel 连接 AIHubMix。此次固定 gpt-5.4-mini；关闭 OpenAI tracing，请求 store=False，但这不替代网关和上游的数据政策。

- Single：分析 → 答案。
- Team：分析初稿 → 独立核查 → 分析修订。角色内部均由 SDK 驱动工具循环。
- 两模式并行、上下文及证据记录隔离；Team 内部顺序执行。核查员可以看到初稿，不能看到 Single 答案。
- 共用 multi-query-v0.2 固定文档/索引，但不会把历史答案或检查表交给模型。

每项事实必须引用已读取 Block 和逐字原文。核查员的引用单独检查是否由它自己读取；引用存在并不保证结论成立，仍需人工审核。

每模式最多 30 次工具调用、15 万返回字符，单次返回最多 6 万字符；每阶段最多 12 轮、180 秒，每次模型输出最多 4,000 tokens。Team 有三个阶段，Single 一个阶段，因此不是等 Token 预算实验，也不代表已设置美元消费上限。

保留输入、短行动理由、工具结果、阶段答案、用量、引用错误和失败状态。不记录私有思维链。失败阶段可能缺少用量，不得计为零成本。输出目录不可覆盖。

Key 仅从当前进程环境的 AIHUBMIX_API_KEY 读取，不存入项目或实验结果。执行命令见英文同名文档。

限制：未固定/独立验证 AIHubMix 的实际底层服务商；三题只用于最小效果观察，不是统计准确率测评。
