状态：已实现并真实运行，分析输出待人工审核。中文与英文版本描述同一范围。

## 范围

只回答：Google Cloud 的 FY2023—FY2025 收入和营业利润如何变化？包含三年数据、两次同比与两年累计变化。不生成 Thesis、原因解释、预测或交易建议；不接入季度材料或原文检索。

Data Agent 与 Analysis Agent 独立：输入是用户已审核的 `run-9856300a8d74fa77` 数据快照，读取前校验审核记录与快照 SHA。数据审核不会自动批准分析结果。

## 实现方式

`src/uteki/agents/cloud_analysis.py` 提供有预算限制的模型循环：

- 模型第一次只收到问题、工具说明和输出约束，没有整包事实或参考答案。
- 每轮模型返回 JSON 动作，本地白名单调度器执行。不是预设读取步骤，也没有引入 Agent 框架。
- `manifest` 给覆盖范围；`facts` 按字段、期间及分页读取；`evidence` 只能查询已读取事实。
- `compare` 只接受已读取、同主体、同指标、同单位且时间递增的两个事实 ID。代码计算变化额与增长率，百分比保留两位小数；基期非正数时不输出常规增长率。
- 最终结构化答案只引用事实/计算 ID。发布前要求两个指标、三年数据、六次变化计算及相应证据全部齐备，禁止附加未经定义的数值字段。
- 模型可生成中英文趋势描述，但程序不把它标为语义已验证。因果解释不在任务范围内。
- 最多 12 轮、40 次工具调用、单轮 8 次；没有静默重试或自动改写答案。

`request_missing` 仍只记录请求。`not_extracted` 表示当前快照没有数据，不意味着申报文件没有披露。无法完成时 Agent 应输出 blocked；本轮没有源文档查找工具。
