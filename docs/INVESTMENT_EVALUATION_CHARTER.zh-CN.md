- 文档版本：v0.1。

- 状态：按讨论建立的评估规范；账户参数尚未冻结，收益测量、持仓标记与组合执行能力待后续实现。提交文档不代表策略或实盘交易已获验收。

## 1. 目标与评价对象

目标是在可承受的风险、资金和流动性约束内，通过有证据的公司研究与资本配置，争取长期、扣除成本后的财富增长，并检验相对被动投资的机会成本。不能以短期排名代替目标，也不能以长期持有为理由延后处理反证。

三种评价独立记录，不合成一个掩盖问题的总分：

| 对象 | 要回答的问题 | 主要证据 |
| --- | --- | --- |
| 研究质量 | 当时的事实、假设、预测、估值和更新是否可靠？ | 冻结的信息、预测版本、正反证据、实际披露与逐项误差 |
| 持仓与决策质量 | 当时价格、资金和风险下，选择与仓位是否合理？ | 决策日志、替代机会、账户快照、情景损失及约束检查 |
| 投资结果 | 扣除成本后赚了多少，承担什么风险，相对替代方案如何？ | 可对账的净值、现金流、基准、归因、回撤和观察区间 |

软件验收另按版本任务书执行。测试通过不证明投资有效；季度盈利不能抵消来源、资金或授权错误。研究正确与价格上涨可以不同步，错误判断也可能暂时盈利，必须分别复盘。

**系统策略、人工操作与整个账户也分别评价。** 手动点击执行不一定是人工决策；人工标成“系统”的持仓也不能直接证明系统能力。分类与口径见第 3 节。

## 2. 周期：季度复盘、年度归因、滚动 3–5 年评价

| 周期 | 固定检查 | 交付与后续 |
| --- | --- | --- |
| 持续跟踪及事件触发 | 财报、重要公告、来源更正、假设反证、估值变化、流动性及约束异常 | Watch 事件与复核事项；重要事件按预设时限处理，不等季末 |
| 每个自然季度 | 持仓逐项复核、预测兑现、共同风险、收益与基准、成本与交易得失 | 季度记录；继续持有、待补资料或调整提案的依据、负责人和复核日期 |
| 每个自然年 | 全年收益及跨季度归因、成功与失败决定、全部成本和规则改进 | 年度评估；解释市场暴露、选股、仓位、交易和汇率影响 |
| 滚动 3 年、5 年及成立以来 | 年化收益、超额表现、回撤、恢复、不同环境中的一致性 | 是否继续、调整或重新验证体系的长期证据 |

不足一年报告实际区间累计收益，不将季度收益外推为长期能力；不满 3 年或 5 年的窗口写“历史不足”。3–5 年也不自动证明稳定超额能力：单一组合、单一行情和重叠窗口限制结论。没有新财报不是“经营没有变化”的证据。

收益按季度末市场估值时点冻结；另记复盘时的研究信息截止时间。季末以后才发布的财报可以指导新决定，不能写成季度内已知信息。缺失披露保持待观察。

季度复盘不等于季度调仓。短期跑输不自动卖出，年度跑赢不自动提高风险额度；调整须有机会比较、风险或假设依据。报告期限、重大事项响应时限在策略登记时固定，延期记录原因。本文件不创建实际定时任务。

## 3. 系统与人工持仓：支持手动标记，按数量归属

### 3.1 分开记录持仓来源、决策来源与执行方式

同一证券可以同时有系统和人工两部分。标记落在成交及其持仓批次/数量上，公司行显示汇总；整只股票的一个标签不足以支持收益归因。

| 维度 | 建议状态 | 规则 |
| --- | --- | --- |
| 持仓归属 | 系统 / 人工 / 待归类；证券汇总可显示混合 | 建仓批次可按数量拆分；同一份数量只能归属一个部分，合计与账户一致 |
| 决策来源 | 系统建议 / 人工独立 / 人工修改系统建议 / 未知 | 建仓、加减仓、退出分别记录，关联对应提案、版本和理由 |
| 执行方式 | 人工操作 / 自动执行 / 未知 | 只说明由谁提交订单，不代替决策来源；由人执行未改动的系统计划仍可属系统 |
| 来源凭据 | 已核实 / 待核实 / 无记录 | “系统”需要可追溯的事前建议及有效组合计划；事后打标不能补造过去证据 |

人工修改系统建议的标的、方向、数量、价格边界或有效期等实质条件，记为“人工修改”，新增头寸进入人工部分，并保留与原系统提案的关联。按原授权计划允许的执行细节调整，不自动改变决策来源。未参与建仓的系统后来覆盖了该公司，不因此接管旧人工头寸。

例：同一股票系统买入 60 股、人工另买 40 股，显示“混合：系统 60 / 人工 40”。即使两笔均由人手工下单，归属仍按决策来源。若人把系统拟买 60 股实质改成 100 股且不能证明独立的两笔决定，记为一笔人工修改的 100 股，不事后拆出“系统成功部分”。以上数量仅说明规则，不是仓位建议。

### 3.2 手动标记与审核留痕

导入持仓没有来源记录时默认“待归类”，支持手动选择系统、人工或拆分数量；有历史建议的才关联并核实为系统来源。仅凭人的回忆所作系统标记显示“待核实”，不进入可核验的系统能力结论。

每次标记或更正保存对象、数量、原值、新值、实际操作者、操作时间、归属生效时间、理由及关联证据。可在界面批量打标，但底层仍保存逐笔分配。界面使用简明标签，核实状态和更正历史可展开查看；打标不采纳研究、不批准组合、不授予交易权限。

禁止根据盈亏改标签美化系统或人工成绩。修正历史归类时，保留原报告，按原成本、真实现金流和费用一致重算受影响的全部区间，并说明变化；不能把改标日当新买入日清零亏损。

实际的管理责任转交与纠正历史错误不同：前者按生效时点、当时公允价值和成对内部划转登记，保留转交前损益；不伪造市场交易。后者重述原归属历史。两者都不改变整个账户的真实资金、持仓和税务批次。

### 3.3 加减仓、分红与人工干预

加仓按该笔新决定单独分配。卖出必须引用所减持的归属数量/批次，使用事前固定的分配规则（明确指定或指定范围内 FIFO 等），不可事后挑选有利成本。策略归属与券商税务批次建立映射，但不能靠打标修改真实税务成本。

若人工决定卖出系统来源的头寸，原持有期间的损益仍计入系统来源部分；本次退出记“人工干预”，保留系统原提案或无提案状态。该实际结果属于“系统来源、有人干预”，不能宣称是未受干预的纯系统策略业绩。不能删除受干预交易再展示一个挑选后的系统收益率。

分红、拆股、公司行动和费用按实际归属数量/权益与冻结规则分摊；卖出后损益继续保留。没有已结算/未结算和资金归属记录时，不仅凭目前持仓标签重建完整历史收益。

### 3.4 分别报告哪些结果

| 报告对象 | 能证明什么 | 必要条件及限制 |
| --- | --- | --- |
| 整个真实账户 | 投资者实际财富与整体回报 | 与券商、现金流和费用对账，是所有拆分结果的核对总账 |
| 系统来源部分的实际结果 | 系统相关头寸实际贡献与管理结果 | 系统标签、来源核实、人工干预完整披露，不等同纯系统策略能力 |
| 人工部分的实际结果 | 人工独立决定及人工修改建议产生的结果 | 两类可再拆分，不把系统提供的研究参考隐去 |
| 待归类/待核实部分 | 数据覆盖与归因缺口 | 数量、资金、损益和占比可见，不能从全账户汇总中删除 |
| 系统按原规则运行的前瞻模拟对照 | 没有临时人工干预时，冻结策略可能产生的结果 | 单独初始资金、规则、交易成本与可成交性假设，保留所有建议；模拟不是实盘 |

给系统、人工及待归类部分分别计算 TWR/XIRR，必须先有各自资本、现金、费用和资金进出账本。共享现金可单列“公共现金”，按事前规则划拨；一次系统与人工之间的资本划拨，在各部分记相反资金流，在整个账户抵消，不是收益。所有证券、现金及费用只能计算一次。

只有持仓标签时，可报告分类市值、已核实损益和账户收益贡献；分类收益率应写“资金基数不足”，不能用盈利除当前市值凑出回报。各部分收益率不能直接相加或取简单平均，需由各自资金路径勾稽到总账户。后续每个部分的基准须按其投资范围及现金流预先固定，不能把系统和人工不同风险的结果直接排名。

## 4. 基准在测量开始前固定

### 4.1 机会成本基准

| 投资范围 | 候选主基准 | 启用条件 |
| --- | --- | --- |
| 以美国大盘股为主 | S&P 500 总回报指数 | 确认范围与币种匹配，固定指数身份、分红/税务口径及数据源 |
| 全球股票 | 如 MSCI ACWI 的适用总回报版本 | 根据市场覆盖、币种、预提税和可投资性选定具体版本 |
| 有稳定地区/资产配置约束 | 对应地区指数或政策组合 | 事前固定组成、权重、现金收益及再平衡规则 |

目前 **S&P 500 是有条件的候选，不是已生效的唯一基准**。正式测量前确定投资范围；实质变化时登记策略/基准新版本与生效日期，保留旧历史，不能事后换一个容易战胜的基准。

主比较用分红再投资的总回报，不用价格指数点位涨幅替代。如果使用低成本基金作代理，须注明证券身份、费用、跟踪差异、分红处理及使用净值还是市场价格；代理不是指数本身。

同时建立“相同资金被动投资”的对照账户：采用真实账户相同外部入金/出金及时间，比较期末财富与资金加权回报。指数总回报是标准，基金对照另含适用成本。外部现金流在 TWR 中被中和，在财富和 XIRR 比较中必须一致。

偏满仓策略不因实际留现金就临时降低股票基准权重，现金的机会成本应显示。只有策略事前规定了稳定的现金或其他资产权重，才采用相应政策组合。

### 4.2 持仓不主动调整的对照

每年开始前冻结“被动延续”对照：年初证券数量和现金相同，不再主动择时或换股。预先定义分红再投资或留现金、外部资金流配置/变现顺序、利息、公司行动、费用、停牌处理。可用按事件前市值比例投入/退出等机械规则，不能看结果后挑规则。

该对照检验主动调整的净效果，不替代市场基准，也不是系统模拟对照：前者保留年初资产、没有主动决定，后者继续按冻结系统规则决策。季度报告使用年度对照的片段，不能每季重置掩盖先前结果。

拆股、并购、分拆和退市按实际权益处理；退出公司的损益不删除。对照不能满足资金或交易约束时报告不可比原因，不假定任意成交。

行业、规模、价值/成长与市场敏感度可作辅助诊断，不替换主基准。跑赢指数称“超额收益”，不直接称风险调整后的 alpha；集中科技、杠杆或更高市场暴露须单列解释。

## 5. 收益、成本与风险口径

### 5.1 先完成账本与估值

固定账户范围、基准币种、估值时间、交易日历、行情与汇率来源。记录证券、现金、应收分红、未结算交易和费用负债。交易日/结算日核算规则一致，避免重复计资金。账户内买卖、分红是内部变化，投资者入金/出金才是账户外部流；分类部分的内部资金划转另按第 3 节处理。

原币和基准币结果均保留。停牌、缺价、迟到汇率及非交易日使用明确估值规则，标记陈旧程度；不以零填充缺失行情。净值未对账时标暂定并列差额与受影响区间。

### 5.2 核心指标

| 指标 | 口径 |
| --- | --- |
| 时间加权收益率 TWR | 每笔外部资金流前后切分子期间，计算不含该流影响的 `r_j`，再 `R = ∏(1 + r_j) − 1`，衡量组合管理效果；不能直接用期末/期初净值 |
| 资金加权收益率 XIRR | 默认报告成立以来的投资者体验，投资者入金为负、提款及期末资产为正，使用实际日期；若计算子区间，期初资产须作为该区间初始负现金流。终值与出金不能重复；无解/多解明确记录 |
| 区间超额与相对财富 | 超额为同区间同币种 `R_p − R_b`（百分点）；相对财富增幅为 `(1 + R_p) / (1 + R_b) − 1`，两者分列 |
| 年化收益 | 满一年后按确切长度 `Y` 年计算 `(1 + R)^(1/Y) − 1`；分别年化组合和基准后相减，称年化收益率差；不将季度超额乘四 |
| 最大回撤与恢复时间 | 从剔除外部流的累计财富指数 `W` 计算：`1 − W_t / max(W_s, s≤t)` 的区间最大值；保留成立以来峰值和跨期未恢复回撤，年末不清零 |
| 贡献与换手 | 报告含已卖出证券的期间贡献、现金/汇率贡献、买卖额、费用及冻结的换手公式；不可只用期末权重乘个股季度涨幅 |

精确 TWR 需要资金流时点估值。只有日度估值时注明日初/日末假设；用 Modified Dietz 等近似必须标为近似并冻结时间权重。归因采用可重放的日度贡献及跨期连接方法，残差与容差明确记录。资金基数为零、非正常净值或无法定义的指标返回不可计算，不静默填零。

XIRR 本身是年化形式，本章程在所选资金流历史满一年后才展示，并标明起止日期及日计数约定；成立不足一年时只列实际现金流、期末财富与区间 TWR。季度报告可以展示已满一年的成立以来 XIRR，但不能把它标成本季度回报。各分部和被动对照采用同样规则。

策略主口径为含分红、扣交易/持有费用、个人资本利得税前收益；预提税及其他税费按实际或事前可比模型记录，实际账户税后结果另列。无法从账本还原时只报可核实口径及限制，不把税后账户与税前指数的差异全部归因于选股。

佣金、税费、适用的管理/托管费均计入。成交价已含的价差/滑点和基金净值已扣的内部费用不能再扣一次；执行偏差可另与决策时价格比较。公司回购的每股经济影响不等于收到分红，不能再次计入总回报。

模型、数据服务和人工研究成本单列，按冻结分摊规则补充扣研究运营成本后的效果；由账户已支付的不重复扣减。工时未计价时报告工时和未知金额，不填零成本。

波动率、跟踪误差或信息比率为辅助指标，说明频率、样本与年化方式；样本不足或分母为零时不下稳定性结论。永久资本损失、偿债和流动性风险仍须经营分析及压力情景，不能用历史波动替代。

## 6. 每笔持仓的合理性

全部持仓按归属复核，已退出头寸及正式决定不买入的候选保留记录。不能只复盘赢家；未深入研究的候选不能直接算研究失败。

| 问题 | 必须记录 |
| --- | --- |
| 为什么继续持有？ | 当前价格/时间、期限、业务质量、假设、情景价值和预期回报；分开盈利增长、现金分配、估值变化，避免重复计算 |
| 什么能证明我们错了？ | 可观察反证、来源、验证时间、到期复核、失效条件；期限延长保留原预测，不能无限后移目标 |
| 为什么是这个仓位？ | 当前/目标权重、区间、预期回报、下行情景、证据可信度、流动性、资金需求及成本 |
| 与其他持仓共同承担什么风险？ | 行业之外的共同驱动，如广告需求、同一客户、AI 资本开支、利率、地域与监管，穿透基金重叠暴露 |
| 相对替代选择如何？ | 同时点其他候选、被动基准、保留现金，含换仓成本及税费；不能因已经买入而降低要求 |

持有依据、仓位合理性、是否交易分别给结论。价格下跌不自动证明适合加仓；资料不足不是默认 HOLD。人工部分也进入全账户风险检查，不能因归类为人工而绕过账户限额。

组合检查单一和头部持仓、共同风险、资金需求与可变现性。“权重 × 情景损失”只能作粗估，需一致的联合情景；不能把公司最坏情景当作独立事件机械相加。压力情景不是损失上限保证，超限与漂移需及时处置。

### 6.1 偏满仓的约束

目标投资比例是偏好，可用资金和风险限额是约束。须配置目标区间、现金缓冲、个股及共同暴露、流动性与再平衡条件；本章程不凭空填写 95% 仓位或 10% 个股上限。

机会不足时明确冲突及取舍。暂留现金、采用被动基金或其他方案哪种允许，需预先纳入策略；不得自动放宽研究/集中度要求或借款填仓。长期多头不推导出杠杆或做空许可。

风险触发重新评估及授权内处置，本文不创建自动止损、清仓规则或真实订单。

## 7. 研究与 Agent 如何评估

| 层次 | 评估项 | 限制 |
| --- | --- | --- |
| Data | 来源、时点/单位/币种、关键缺口、更正与过时状态 | 有引用不等于支持；后来重述不等于当时可知 |
| Analysis / Team | 假设及反证、财务/估值复算、预测误差、未知和跨领域一致性 | 内部 Reviewer 不代替外部评测；股价短期上涨不证明因果判断 |
| Watch → Review → Update | 重大遗漏、误触发、可得信息至复核完成的滞后、过时建议暴露 | 抓取失败、复核失败与经检查无变化分别记录 |
| Portfolio / Risk | 仓位理由、约束、共同暴露、压力情景及相对对照的效果 | 满仓、股票数量和高收益都不能单独证明配置合理 |
| Execution | 授权、幂等、账本、执行偏差与费用 | 模拟不等于实盘；提交不等于成交 |

预测在公布结果前冻结定义、单位、期限、点值/区间和信息截止。用适合指标的绝对/相对误差；接近零或负实际值时避免误用百分比误差。区间同时报告覆盖率和宽度，不能靠无限放宽提高覆盖。

概率校准仅用于事前有明确事件、概率、日期和判定规则的预测。二元事件可用 Brier 分数 `mean((p − y)^2)`，同时报告样本量、未决事件及基率对照；不能给旧叙述事后补概率，少量相关样本也不证明稳定校准。

single、multi、team 用相同任务、来源和截止信息比较，预算差异单列，保留全部尝试及人工负担。账户收益是端到端结果；不根据一笔盈利给单个 Agent 归功，不把人工干预效果直接算给系统。

## 8. 事前记录与变更纪律

每次买卖、增减仓和正式复核后的不操作决定，至少保存：

| 字段组 | 最小内容 |
| --- | --- |
| 身份与时间 | 决策 ID、公司/证券/账户、案例/策略版本、提出与决定时间、信息截止、价格/汇率时间 |
| 研究依据 | 来源、假设、反证、预测/模型、未知、适用期限、下一复核及触发 |
| 归属与干预 | 持仓数量分配、决策来源、执行方式、来源核实、打标/更正记录、受人工干预的步骤 |
| 资本配置 | 当前/目标仓位、情景、资金和未完成订单、替代机会、成本与风险检查 |
| 人的决定 | 原提案、人工接受/修改/拒绝、理由及真实负责人，不能由模型代签 |
| 后续结果 | 授权引用、真实成交及费用、偏离提案原因、观察结果和复盘 |

研究采纳、组合批准和执行授权分别记录；归属打标不替代任何一种。无新证据的重复运行可关联同一事件，不制造重复成功记录。

每季固定数据填写模板，年度汇总并做跨期归因。Analysis 负责预测、反证及更新，Portfolio 负责配置与替代比较，Risk 独立记录约束，Execution/账本提供实际结果，评估从冻结记录复算。项目负责人作最终判断；一人兼任时如实说明。

策略、基准、阈值、标签规则及指标定义的变更保留版本、原因、生效时间和负责人。数据/归类错误可一致重述历史，但保留原报告；策略变更仅前瞻生效，历史模拟另标实验。

实盘、前瞻模拟和历史回测分开报告。回测保留当时投资范围、退市公司、发布时间、价格、成本，说明模型可能知道未来信息的限制。报告全部预登记样本、失败和时间窗口，不拼接最好片段，不以多个重叠窗口冒充独立成功。

## 10. 版本衔接与验收

本次交付为章程与模板，**不新增 v0.2/M0 任务和验收门槛**，不实现持仓打标界面、不接入账户或交易。

| 阶段 | 纳入对应版本任务书的内容 | 验收依据 |
| --- | --- | --- |
| v0.2 | 来源、研究 benchmark 与实验可复现 | 沿用 G0–G4，章程或收益叙事不替代人工研究验收 |
| v0.3–v0.4 | 事前预测、情景、反证、期限与团队记录 | 可还原当时判断和版本；未到期假设保持待观察 |
| v0.5 | 事件及季度到期复核、覆盖和滞后 | 连续信息流可回放，无变化/资料不足有依据，重大反证不等季末 |
| v0.6 | 只读持仓导入及手动归属标记 | 系统/人工/待归类可按数量分开，同股混合、变更留痕及覆盖率可核对 |
| v0.7 | 分部资金、策略/基准/对照、仓位与风险提案 | 各部分与总账户勾稽，资金划转不产生收益，人工头寸计入账户风险 |
| v0.8–v0.9 | 模拟/实盘账本、归因及真实费用 | 同输入可复算，同现金流基准可核对；模拟与实盘分别验收，实盘另需授权 |

收益工程验收覆盖入出金、分红、费用、跨币种、公司行动、缺价、跨期回撤和零资金等异常；归因残差与对账满足预设容差，无效结果显式失败。

归属专项验收覆盖：同股混合、人工执行系统计划、实质修改、未知导入、部分卖出、分红/拆股、人工退出系统头寸、内部划转、历史改标及报告重述。数量、现金和费用无重复遗漏；分类改变不改变总账户净值，盈利/亏损不能被移出汇总。

研究复盘验收要求全部应复核持仓和重大事项有处置、证据及负责人，到期/未到期分别统计。缺记录写待补，需时间写待观察。长期效果同时报告收益、风险、成本和样本限制，由负责人判断；未来自动化升级标准在验证前登记，本版不虚构超额目标或达标结论。
