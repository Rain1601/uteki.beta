# 投资季度复盘模板

按 [投资与评估章程](INVESTMENT_EVALUATION_CHARTER.zh-CN.md)复制填写。空值表示未记录，不代表零或通过；持仓标签、复盘决定都不构成交易授权。年度可复用本模板，按全年连接收益及归因，不简单相加季度回报。

## 1. 身份与完整性

- 报告 ID / 版本 / 季度或年度：
- 评估区间及估值截止时间（含时区）：
- 研究信息截止时间 / 实际复盘日期：
- 实盘 / 前瞻模拟 / 历史回测：
- 策略版本、账户范围、基准币种：
- 主基准身份、总回报/预提税版本、数据源；可投资代理及差异：
- 净值、行情、汇率、现金流、费用、决策及归属快照路径/指纹：
- 计算与配置版本、重放步骤：
- 对账差异、缺价/估计值、TWR 精确或近似及其假设：
- 执行者、研究复核者、最终负责人；兼任情况：
- 状态：待补 / 待复盘 / 已复盘（需真实签收）。

个人账户、资金明细和认证信息留在获准的私有位置；版本库中的模板不要求公开这些数据。
