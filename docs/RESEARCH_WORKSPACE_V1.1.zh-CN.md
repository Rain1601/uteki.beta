# 研究档案 v1.1 · 研究者独立演进

2026-09-14。对应英文：RESEARCH_WORKSPACE_V1.1.md。本文件替代 v1.0 中共用采纳位、先归档再替换以及采纳后自动归档其他候选的规则。

## 后端契约

- 唯一采纳位：公司 + researcher_id + 研究主题 + 主材料。年份仅为展示组织，不合并不同季报。
- researcher_id 是稳定方案身份；mode、模型及提示词配置版本不是研究者身份。现有已核对的两次 open-drivers 实验映射为 single-default / team-a；其他历史配置未声明身份时进入 unassigned，禁止采纳或上下文继承。
- 新运行仍通过 seed 导入为 candidate，不覆盖历史。导入保存 manifest 哈希为 config_version，原路径和产物哈希保留。新团队应在 manifest.researchers 中按 mode 声明 id/label，不凭 team 字样归并。
- adopted 为唯一生效状态，由状态推导当前版本，不维护第二份可能失配的 current 指针。
- 采纳有旧生效版本时，必须同时提交 replace_snapshot_id、replace_revision、expected_slot_revision。组令牌覆盖组内所有快照 ID、状态、修订计数，能检测采纳后又归档等往返变化。锁内验证并一次提交旧版归档和新版生效，旧版记录 replaced_by_snapshot_id；其他候选不受影响。
- candidate 可 reject（必须填原因），rejected 可 reconsider 回到 candidate，不能直接采纳。归档、软删除、恢复不自动递补生效报告。证据校验失败和主材料待确认仍是采纳门槛。
- edit 可从生效、候选、归档或拒绝版本派生；原文不变。保存 parent_snapshot_id、edited_at、作者、修改说明和 edit_diff；不伪造模型运行时间。新修订 validation_status=pending，清除旧审核签名。
- 当前编辑器支持原有判断正文、未知项和验证线索；保留判断数量、顺序、引用对象及其他结构字段。新增/删除判断、修改来源属于后续证据修复流程，不通过文字编辑绕过。人工复核仍要求原来源通过校验，不可仅凭说明洗掉旧引用错误。
- 意见不自动复制到新修订；划线仍绑定原快照。历史操作和修订差异均可查看；阅读划线审计不注入研究上下文。

## 上下文

- build_context / Store.context 增加 researcher_id；只有一个已明确研究者时允许旧调用省略，多研究者必须选择。
- 按公司、研究者、主题及时间边界筛选已采纳结果，最近一份作基线，更早结果按需读取；拒绝、未采纳、归档、删除及待归类结果排除。
- 按需历史读取和意见源归属均重复校验研究者，不只靠界面隐藏。新冻结清单 schema_version=1.1 包含研究者；旧冻结文件不改写，缺乏隔离身份的旧历史访问不能静默升级。
- 替换/撤回上游标记后代需复核，不自动失效或重跑；新上下文附带提示，已冻结运行输入不变。
- 目前完成上下文筛选、冻结和读取接口；未接入实际模型执行、人工意见逐轮语义复核。本轮无付费调用。

## 迁移

Store.migrate_researchers(identities, dry_run=True) 先预览。正式执行在锁内校验来源未变，先创建带 SHA 的字节级 .bak，再原子写入 schema 1.1 和映射审计。快照内容、ID、状态、评论、划线和原事件保留；父修订继承已确认身份；未知归类不猜测。发现重复生效位或循环父关系则停止。重复执行不改动文件。

服务启动先执行上述幂等迁移，再幂等导入真实实验；不自动采纳。回退需停止服务并使用匹配备份及旧代码，迁移后产生新用户记录时不得直接回退覆盖。

## 最小界面

研究者/主题下拉；每份主材料一行。优先生效报告，无生效报告时明确预览候选。待审核及历史默认折叠。旧 snapshot 链接推导研究者，显式过滤与快照冲突时拒绝混合展示。URL 保留筛选和版本。公司列表、Data Agent 原文、证据抽屉与中文辅助翻译不重做。

验证：见 tests/unit/test_researcher_streams.py 及原档案/上下文/路由/划线回归。浏览器写操作仅在独立临时档案中验证，不对真实档案执行测试采纳。
