# Uteki 1.0 delivery plan / 今日交付计划

Plan date: 2026-09-15. Status: approved; implementation in progress, not a release claim.
Progress checkpoint: 2026-09-16 Asia/Shanghai. The original same-day target was
not met. Do not backdate completion or relabel the current experiments as 1.0.

## 1. Outcome / 交付目标

Alphabet 的本地单用户研究工作台：10-K 初始化一份可读、可追溯的年度报告；
后续 10-Q / 电话会检验已有判断并提出修订；人工确认后年度报告生成新版本；
能看到具体改了什么、为何修改、使用什么材料、花了多少钱。

Target: an end-to-end local, single-user Alphabet research workflow, not a
multi-company production service or a claim of proven investment performance.

“今天完成”是排期目标，不是允许降低质量门槛。分别交付工程验收、模型效果
验收、人工研究审核；未通过时标记 1.0-candidate 和未完成项，不能宣称正式通过。
日期按 Asia/Shanghai；若执行跨日，记录真实完成时间，不回填日期。

## 2. Baseline / 已知现状

- SEC 多期目录、Source Blocks、原文定位、工具化读取已存在。
- 已有一组官方电话会/发布稿接入，不等于历年完整覆盖。
- Single / Team 运行与费用记录存在；新年度叙事仍是独立实验入口。
- 研究者隔离、唯一生效位、不可变修订、划线意见、上下文冻结有后端基础。
- 带意见重跑已有后端入口，但页面运行、结果回档和真实效果尚未完整验收。
- 季报驱动年度修订仍有隔离 Demo，不能当成正式持久化功能。
- 最新 annual-narrative-single-v0.1：6 次模型调用，17 次工具调用；估算
  USD 0.10157475；3 个未读取 Block 造成 8 处引用失败。原始产物保留。
- 部分旧方案仍写 M0 或前两年默认全文继承，需要明确 supersession。

## 3. Scope / 范围与规则

### Today / 今日范围

- 一家公司：Alphabet；以 FY2025 10-K → 2026 Q1 → 2026 Q2 为主链。
- 接入可核实的相关官方电话会和发布稿，并选择至少一组关键竞对材料，
  用于检查研究增量。无法取得/确认公开时间时记录缺口，不冒充已覆盖。
- Single 是首要验收路径；保留 Team，并在相同材料/问题/预算上限下做一组对照。
- 报告包含核心判断、业务、行业、赚钱与增长、估值、后续关注。
  内部问题和论证自主，不按冗长固定问卷填空。
- 五部分结构用于阅读；事实/推断/未知、证据、时间与修订关系是稳定契约。
- 原始披露、模型原始输出、人工修订分别保留，不原地覆盖。
- 默认公司 + researcher_id + scope + 主材料最多一个生效报告。
- 季报不自动改年度报告。人工确认才产生生效修订；未采纳结果只供预览。
- “支持/削弱/反驳/不足/混合”描述证据状态，不宣称永久证实。
  不按引用数量自动加深绿色；重复来源不能变成更多独立证据。

### Not today / 明确暂缓

50 家公司扩展、历年所有电话会回填、自动交易/仓位管理、动态复杂 Team、
正式 A2A/MCP 适配、模型训练/强化学习、全量 OCR/翻译、云部署/多租户。
不以这些扩展替代本次年度研究闭环。

## 4. Work packages / 工作包

按 A → B → C → D → E → F 推进。时间为净工作量估计，不是完成保证；
串行路径约 8–12 小时，材料获取、模型响应、人工审核可能延长。

### A. Reliable annual run / 修复年度分析（1.5–2 小时）

- [x] 保留 v0.1 原始失败；新建版本，先分类读取遗漏、错误证据、数值与推断问题。
- [x] 将叙事报告运行封装为应用可复用入口，旧实验和 Claims 输出保持兼容。
- [x] 最终引用只能使用实际成功读取、属于本次批准材料的证据。
- [x] 校验失败最多触发 1 次有预算上限的补读/修订；重新检查全部最终引用。
      禁止偷偷替换为附近 Block、只删除错误项洗成成功、无限循环修复。
- [ ] 数值校验明确期间、币种、单位、公式和母子业务口径；无法自动检查的
      声明标为待复核，不把全篇标为数字已验证。
- [x] 输出结构检查和语义审核分开。数字存在不等于支持整句判断。
- [x] 同材料、同配置运行两次，记录差异；修复前后单独比较，不据两次推断统计稳定。

进度：v0.2 与 v0.3 各两次；v0.4 与 v0.5 各一次，共新增六次年度实验。v0.4 引用通过但
若干计算失败后仍出现错误百分比。已增加保守的百分比来源/计算覆盖拦截，
离线回放可识别这些数字；v0.5 实测经过一次修订后仍有 40.89% 缺少计算依据，
被正确拦截为未通过。引用错误已消除，但不是完整数字审计或研究质量通过。
所有候选仍未通过研究审核、未采纳。A 的整体验收尚未完成。

验收：无未读取引用；计算测试通过；人工抽检核心结论依据，未解决错误明确阻止采纳。

### B. Report + hypothesis contract / 报告与判断契约（1–1.5 小时）

- [ ] 稳定 report_id / revision_id / hypothesis_id，结论与追踪对象分离。
- [ ] 关键判断记录：陈述、业务范围、期限、条件、支持/反对证据、观察项、重审条件。
- [ ] 验证记录保留验证者、材料版本、被验证的具体 hypothesis revision、公开日期。
- [ ] 允许新判断和混合证据；没有覆盖不等于支持、失效或删除。
- [ ] 模型输出保留，不在渲染层人工重写标题/论证冒充模型改进。
- [ ] 新格式兼容既有研究档案；迁移先预览/备份，不改历史内容与身份。

验收：报告可以自然阅读；同一判断可跨修订追踪；来源与判断不是靠文本相似度硬配。

进度：已新增 `hypothesis_contract.py` 纯数据契约与修订预览校验：稳定判断身份、
明确版本目标、证据状态、日期边界、研究者隔离、撤回保留、旧版本不变。
尚未接入模型输出、档案持久化和页面，B 不标记整体完成。

### C. Validation and human revision / 验证与人工修订（2–3 小时）

- [ ] Q1 输入：当前已采纳 FY2025 年度报告 + Q1 合规新材料。
- [ ] Q2 输入：当前年度生效修订 + 与本次相关的已采纳 Q1 验证记录；
      去重，不把 Q1 全文与所有旧年报无界拼接。
- [ ] 下一年 10-K：上一年度最终生效修订为默认基线，更早年份按需读取。
- [ ] 人工意见作为待核查输入，每次逐条接受/部分接受/拒绝/未解决并说明证据。
- [ ] 验证报告提出修订 diff：新增、变更、撤回，附基线 revision 和来源。
- [ ] 确认时校验基线仍一致；原子保存新修订与审计，旧版保留。
- [ ] 上游替换/撤回后，受影响下游标为需复核；旧运行输入永不追改。
- [ ] 同版重跑可显式载入未采纳草稿和意见，但不得混成跨材料已采纳基线。
- [ ] 严格材料时间过滤；今天生成的历史研究明确标为回顾实验。
      模型预训练知识无法被时间过滤消除，不宣传真正盲测。

验收：用隔离测试档案走完 年报 → Q1 → 人工修订 → Q2；持久化、刷新、
双标签冲突、历史还原均通过。真实报告采纳由用户完成，不自动替用户操作。

### D. Data and valuation / 数据与估值（1–2 小时）

- [ ] 核对 10-K/Q1/Q2 材料、官方电话会/发布稿覆盖与公开时间精度。
- [ ] 增加一组关键竞对材料的最小对照：同问题，有/无新增材料，检查增量而非篇幅。
- [ ] 获取有日期/来源的价格、股数、现金、债务；区分 GOOG/GOOGL、全公司股本
      和单类别报价、拆股调整及数据实际可用日期。
- [ ] 独立计算估值情景与敏感性：所有假设可见，可复算，不把情景估值当事实。
- [ ] 业务验证与价格表现分别呈现；明确持有期、基准、股息口径。
      不用短期股价方向给经营假设打真伪标签。
- [ ] 缺数据时返回具体缺口，不编目标价。若估值数据闭环无法完成，标记该功能
      未交付；“允许不知道”不能替代计划中的估值工程验收。

### E. Product integration / 正式工作流（1.5–2 小时）

- [ ] 公司页保留研究者、材料/版本列表和正文布局；companies 页不改。

- [ ] 任务状态：queued/running/succeeded/needs_review/failed/cancelled；

- [ ] 冻结材料、上下文、模型/提示词/代码版本；运行记录不包含 Key。
- [ ] 生成结果自动进入对应研究者/主题的候选列表，但不自动采纳。
- [ ] 新年度格式支持划线意见、证据查看、验证记录和人工修订。

- [ ] 依照 frontend-design：简洁连续阅读，中英文控件，中文短引文/英文原文

- [ ] 本地 .env 安全加载、Git 忽略、权限检查；不执行配置内容，不在请求/日志回显。
- [ ] 本地写入接口检查请求来源；服务仅绑定 loopback，不增加公网暴露。

### F. Evaluation and release / 效果验收与交付（1–1.5 小时）

- [ ] 固定至少 6 个案例：年报初始化、数值/口径、Q1 验证、Q2 继承、错误人工
      意见、缺失/超时点材料；可将补充材料价值检查纳入案例。
- [ ] 离线回归：引用拒绝/修复、预算/超时、上下文权限、并发生效位、迁移、
      修订依赖、UI 路由；不在真实用户档案做测试采纳。
- [ ] 模型实测：年度两次、Q1/Q2 链、错误意见压力测试；预算允许下做一组
      Single/Team 对照。若缺预算，明确记录哪个实测未做。
- [ ] 审核维度：事实/计算、证据支持、核心论点、因果与反证、可验证性、
      重要遗漏、校准与未知、可读性。不得按 Cloud/Services 排名是否符合偏好评分。
- [ ] 更强模型仅可作为辅助审核，预算内单独记录；不能取代原文核实和人工验收。
- [ ] 保存逐案错误与改善，不用综合平均分掩盖重大事实/引用错误。
- [ ] 提交完成/未完成清单、已知限制、费用、测试结果、可打开页面和复现入口。
- [ ] 更新 README 与双语规范；明确替代旧默认继承规则，旧运行冻结输入不变。

## 5. Budget / 费用与停止条件

用户已确认推荐的新增累计估算预算 USD 5。由共享 SQLite 账本预留在途请求，
不是每次运行各有 USD 5。当前新增估算 USD 1.78700775，实际账单未知。
旧 v0.1 的 USD 0.10157475 不计入本轮额度。新年度入口支持私有 .env 加载，
不回显 Key。旧的其他运行入口尚未全部统一接入新共享预算，不能宣称全局覆盖。

- 每次请求保存开始/结束状态、输入/输出/缓存 tokens、估算费用、未知费用。
- 记录估价来源及日期；不能把缓存折扣猜成实际账单。
- 运行前基于输入与最大输出预留预算，计入并行在途请求；余量不足不启动。
- 未知费用不是零费用，停止自动后续请求并提示人工核查。
- 单次 API 已在途可能产生费用；平台实际账单硬上限不能由本地估算保证。
- 超预算/超时/无法获取合规材料时不扩权、不绕过、不无限重试；报告具体缺口。

## 6. Release gates / 发布门槛

Engineering: source fidelity, traceable reads, valid state transitions, immutable
revisions, bounded runs, preserved history and functioning review UI.

Research: no known material factual/computation/citation defect in an adopted
candidate; explicit uncertainty, useful testable judgments, reviewable counterevidence.
No promise of investment profitability or proof from a handful of experiments.

Human: user approves the exact annual report and proposed revisions. Technical
validation does not equal research approval. Without human approval deliver a
working 1.0 candidate, not an automatically approved annual baseline.
