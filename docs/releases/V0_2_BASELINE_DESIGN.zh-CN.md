# v0.2 baseline 设计登记（尚未冻结）

状态：R2-A 开发记录。人工 G0 尚未完成，Gold、模型及预算尚未确定，本文不是实验结果或运行许可。对应任务 V2-05 / V2-08。

## 研究输入和任务范围

固定文件为 Alphabet FY2025 10-K，Accession `0001652044-26-000018`，官方地址：
<https://www.sec.gov/Archives/edgar/data/1652044/000165204426000018/goog-20251231.htm>。

2026-09-18 重新取得的文件作为新 candidate 保存。旧原文 SHA 不可恢复；新原文的 1,311 段与历史段落契约完全一致。来源批准、业务粒度及证据语义仍需人工 G0。来源取得及技术验证见 R2-A 执行记录。

公共入口默认选取 Item 1（第 52–142 段）。旧候选的 22 条证据包含第 506、557、772–792 段等财务披露，不能用只读 Item 1 的输出与完整候选评分后，把不可见材料的遗漏归因给模型。

本轮提供显式全文模式：请求的两个章节边界同时设为 `None`；默认 Item 1 行为保持兼容。建议完整 M0 baseline 使用已核验的全文段落，并在 G0/G1 冻结时确认评价的来源范围。如果最终选择小节实验，Gold 和评分分母也必须限定于同一可见范围，使用独立身份。

全文输入需先按选定模型估算 token 和费用。如果超出上限，停止并登记新的输入策略；不得静默截断、自动换模型或在取得结果后补喂 Gold。文档索引用于定位和阅读；现代 block ordinal 与 legacy paragraph ordinal 是不同定位体系，不能混用。

## 最小运行契约

| 项 | 当前开发约定 |
| --- | --- |
| 请求 | 已核验 `Document`、明确的章节或全文选择；输入段落及每段指纹进入运行记录 |
| 配置 | 已实现 model、prompt version、temperature；provider 适配、输入与费用限制仍由待开发的正式 runner 管理，不能假定已有预算保护 |
| 新提示 | 显式选择 `business-map-v0.2`，完整列出嵌套输出结构；保留旧 `business-map-v0.1` 选择 |
| 输出 | `BusinessMapAgentResult`：candidate、run record、原始模型输出；模型不能写人工接受或采纳状态 |
| 失败 | `BusinessMapRunError`：失败阶段、原因、可取得的原始输出、已知 token/费用；未知费用为 null |
| 来源验证 | 文档/URL/段落/文本指纹一致；证据必须属于实际发给模型的段落集合 |
| 推导规则 | v0.2 请求尚未携带已批准的确定性规则，故当前只接受 explicit/unknown；derived 会被拒绝并记录失败，不能靠模型自述推导规则放行 |
| 人工边界 | 能定位不等于语义支持；成功运行不等于 Gold 或已采纳研究 |
| 调用方责任 | 原样持久化成功和失败记录、原始输出、完整 prompt/config、代码身份；不只保留最好一次 |

单次调用以公共 request/config/result 协作，不依赖某个模型会话的私有记忆。后续 Analysis team 的任务分派、共享研究状态、Watch/Review/Update 按 v0.3–v0.5 实现；当前没有常驻 team 或调度器。

## 来源白名单与评价隔离

运行时可见材料限定为该固定快照的选定段落和机械来源身份。实际传入模型的全部文本会记录指纹。`BusinessMapAgent` 通过注入的 model port 工作，本身不读取 benchmark、人工审核、评价结果、公司历史报告、网络或工具返回。

这是一条公共输入边界，不是任意 Python adapter 的操作系统沙箱。正式 baseline runner 尚需固定一个无额外文件/网络工具的适配器，在隔离目录中只提供白名单资料，并记录它读过的文件和工具。未验证该运行入口前，V2-05 不得标记“Gold 隔离已验收”。

评价端单独持有 Gold 和处置记录。当前开发者及本轮协作 Agent 已接触旧 `v0.1-candidate` 的业务地图、42 条 claims、65 条 spans、旧 excerpt、pilot 和 G0 文档；也已接触本轮待审候选。**本试点不是盲测**。

未来跨公司能力需要预先划出未用于 prompt/流程调优的公司与申报文件。本版未预留可信跨公司测试集，也不作泛化结论。看到完整 Gold 后的任何提示修改另记实验版本，不回写初始 baseline。
