# 阅读上下文修复 / Reading context repair v0.2

## 范围与版本

纯工程修复，无 LLM 调用、无独立 Analysis Agent。4 份年报新增 v0.5-candidate（递归展开 DOM/XBRL）；旧冻结索引、目录指针和所有源文件保持不变。季度仍使用原 v0.4-candidate。reading-groups v0.2 为独立派生层。

## 已核验

- 四份年度候选均保留原表格/图片/Part/Item 数量，0 索引 diagnostics。冻结旧索引文件 SHA 均通过验证。
- 跨页列表读取包含前页冒号引导段和标题；页眉页脚保留来源记录，阅读展示省略。
- 明确的 •/◦ 符号保留父子结构，Gemini Enterprise 与 Gemini for Google Workspace 归属于 Agents，不推断其他业务层级。
- 不再把含多个圆点的复合大 Block 当作单个列表项。FY2025 Cloud 旧 #770 通过新解析拆开，收入来源返回 5 Blocks / 651 字符，而不是 4 Blocks / 7,969 字符的混杂内容。
- 表格自动附带邻近标题、单位引导和紧随的标记注释。四次目标表格读取都有单位；财务年份与金额保留。
- 106 项测试通过。人工视觉与业务审核仍 pending。

## 重跑的含义

重放旧实验 33 次已知调用，通过正文匹配映射新 Block；旧 #770 特别映射至 Cloud 收入引导句。这是固定路径的工程回归，不是重新证明自主检索能力。六题候选答案核对依据后沿用，非新模型输出。旧版需要额外查询单位的步骤仍保留，所以不能声称本次实际调用次数降低。Q6 依旧明确材料不足。

## 限制

- 只恢复明确符号标记的两级列表，不声称通用语义层级识别。
- 表格上下文是邻近规则；远处引用的注释、跨页注释及全文单位声明并未通用解析。不允许把“相关注释全部读取”视为保证。
- 混合直接文本的 DOM 容器仍保守保留；本次不宣称所有年报分块问题已解决。
- 本轮版本不自动替换 catalog 中冻结文档。Inspector 可直接访问各年报 indexes/v0.5-candidate；审核后再决定是否切换默认。
